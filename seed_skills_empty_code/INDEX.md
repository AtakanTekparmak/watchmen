# Seed Skills Index (E1 — empty-code baseline)

Empty baseline for the skills-with-code evolution track. Contains a single
placeholder skill with no `scripts/`, `references/`, `templates/`, or
`assets/` subdirs. The evolution loop is allowed to add executable helpers
but starts from zero utility code. Used as the control arm against E2
(`seed_skills_1_code/`) and E3 (`seed_skills_5_code/`).

- **placeholder/** — Intentionally empty skill. No guidance, no scripts. Evolution must manufacture any code from scratch.
